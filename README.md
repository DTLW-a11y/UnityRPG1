#### PART 2 游戏介绍

- **类型：**横板RPG+（轻微）类银河恶魔城玩法

​	以RPG类型为主体，包含<u>打怪升级、任务驱动、剧情叙事、装备收集/合成</u>等经典元素，同时辅以类银河恶魔城中的<u>地图探索、能力锁</u>等元素来增加游戏可玩性和玩家的探索欲望

- **玩法：**打怪升级+剧情叙事

  以剧情串联游戏流程，通过打怪升级、探索地图寻找宝箱、获得装备来提升数值，最终战胜boss结束

- **内容：**

  游戏流程：**见”剧情.md“**

  除了主要的剧情以外，游戏内还有：

  - 背包系统（B键），含装备、物品栏、合成站、玩家面板，可查看当前的角色数值、使用可消耗物品、装上/卸下装备、使用材料合成装备
  - 任务系统（T键），可查看当前接取的和已完成的任务
  - 菜单栏系统（esc键），可暂停游戏、退出游戏、返回开始页面
  - 等级系统，打怪、完成任务、打开宝箱获取经验值以升级，可提升最大生命值等角色数值
  - 技能系统，有二段跳、盾击、发射火球三个能力，其中火球消耗魔力值，装备主角家二楼的魔力书，在打怪时可提升魔力等级
  - 四个宝箱，可获取装备、血瓶等，其中一个在场景Forest3的左侧隐藏场景中，需用盾击能力进入
  - 存档点系统，靠近篝火按e键可以保存位置，死亡后在上一次存档的地方复活
  - 敌人：共设计四种敌人，包括一个最终boss，设计有两个阶段
